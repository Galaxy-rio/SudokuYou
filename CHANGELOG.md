# Changelog

All notable changes to Sudoku You are documented in this file.

## [2.0.0] - 2026-08-25

- First stable release under the Sudoku You name.
- Added four offline puzzle difficulties with unique-solution generation and automatic saves.
- Added step-by-step logical hints, pencil marks, advanced annotations, undo, and redo.
- Added import and export support for seven Sudoku text formats.
- Added per-difficulty statistics and extensive Material 3 appearance options.
- Added English and Simplified Chinese language selection.
- Added local-only crash history and a third-party open-source license viewer.
- Fixed the release launcher's circular fallback icon on physical devices.
- Released the project under GPL-3.0-or-later.
