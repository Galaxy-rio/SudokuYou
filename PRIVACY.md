# Privacy Policy

Effective date: 2026-08-24

Sudoku You is designed to work offline. The app does not request Android's `INTERNET` permission and includes no advertising, analytics, tracking, user accounts, or telemetry SDKs.

## Data stored by the app

Sudoku You stores the following data locally on the device:

- Generated or imported puzzles and saved game progress
- Gameplay statistics
- Appearance, language, and gameplay preferences
- Advanced board annotations
- Local crash reports

Crash reports can contain exception messages, device and Android version information, thread names, and stack traces. They are kept in the app's no-backup storage for up to 30 days and are limited to 20 reports. They are never uploaded automatically. A report leaves the app only when the user explicitly copies or shares it using Android's system interface.

## Backups and exports

Android system backup is enabled for ordinary application data. Depending on the device and the user's system settings, Android or the selected backup provider may back up eligible game data and preferences. Crash reports are stored in a no-backup directory and are excluded from system backup.

Puzzle exports and shared crash reports are initiated explicitly by the user and are handled by the destination selected in Android's system interface.

## Contact and changes

Privacy questions and bug reports can be submitted through the project's public issue tracker. Material changes to this policy will be documented in the repository and included with a future release.

# 隐私政策

生效日期：2026-08-24

Sudoku You 被设计为完全离线运行。应用不申请 Android 的 `INTERNET` 权限，也不包含广告、分析、追踪、用户账户或遥测 SDK。

应用会在设备本地保存题目和对局进度、游戏统计、外观与游戏设置、高级盘面标注，以及本地崩溃报告。崩溃报告最多保留 30 天和 20 份，存放在不参与系统备份的目录中，绝不会自动上传。只有用户主动复制或通过 Android 系统分享时，报告才会离开应用。

普通应用数据允许参与 Android 系统备份。是否备份符合条件的对局数据和设置，取决于设备、系统设置及用户选择的备份服务。题目导出和崩溃报告分享也只会在用户明确操作后发生。
